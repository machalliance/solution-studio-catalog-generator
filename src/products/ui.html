Settings

Source system
The host directories Product Catalog Generator reads and writes. Saving here stages a new value in .env — a container can't remount itself, so it takes effect on the next recreate, not immediately.
Saved, but not yet live — this container is still running with the old path(s). Run this on the host to apply it: docker compose up -d --force-recreate
Catalogs & categories
A catalog is a top-level grouping (like Clothing or Home) with its own base image prompt. Each catalog has one or more categories, shown as sections in the sidebar. A category name can exist independently in more than one catalog.
Models
Which models to use, and how to reach them. Model IDs are provider/name — on the direct route the prefix picks the vendor, on the others it's passed through as-is. Endpoints and API keys are set in .env, not here.
Batch item generation, export-map drafting, schema lookup.

Brand names
Off by default — the batch generator omits the "brand" field entirely rather than risk a real, currently-trading company name. When on, it's required to invent a fictional house-brand instead.
Set SHOW_BRAND=true in .env to turn on — requires container restart to take effect.
